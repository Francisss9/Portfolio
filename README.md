## Kota

**Orçamentos de reparação para oficinas, no telemóvel e no computador, sem internet.**

O Kota cria orçamentos em PDF com totais exatos, numeração sequencial e a marca da oficina. Os dados ficam cifrados no próprio dispositivo: sem conta, sem nuvem, sem anúncios.

### Descarregar

Em cada versão encontra os instaladores para todos os dispositivos, na [página de versões](https://github.com/Francisss9/Portfolio/releases?q=kota):

- **Android:** `Kota-X.Y.Z.apk`
- **Windows (x64, portátil):** `Kota-X.Y.Z-x64.exe`, sem instalação: guarde numa pasta e abra.

**No Android:** descarregue o `.apk`, permita a instalação a partir de fontes desconhecidas quando o Android perguntar, abra o ficheiro e toque em **Instalar**. Se já tem o Kota, a instalação faz-se por cima e os dados mantêm-se.

Cada versão inclui um ficheiro `SHA256SUMS` para confirmar a integridade do descarregado. Para emitir PDF é necessária uma licença, ativada na aplicação em **Definições → Licença**. Há uma experiência gratuita de 7 dias, por pedido.
